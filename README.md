## About

This repository contains my personal homepage, designed for teachers, classmates, and potential research collaborators.

I am **Changping Lu (路长平)**, a master's student in Computer Technology at Shenzhen University. My current interests include computer vision and image segmentation. The website presents my education, competition experience, projects, honors, professional skills, and passion for long-distance running.

个人主页以英文为主要展示语言，用于介绍我的学习经历、竞赛项目、荣誉技能和兴趣爱好。整体视觉灵感来自《强风吹拂》，通过浅色渐变、大面积留白和流动线条表现清晨、奔跑与持续向前的力量感。

## Run Locally

Because this is a static website, it can be opened directly or served with a lightweight local server.

### Option 1: Open directly

Download or clone the repository, then open `index.html` in a browser.

### Option 2: Start a local server

```bash
git clone https://github.com/xiaolu135/xiaolu135.github.io.git
cd xiaolu135.github.io
python -m http.server 8000
```

Then visit:

```text
http://127.0.0.1:8000/
```

## Deployment

The homepage is deployed from the root directory of the `main` branch.

To publish an update:

```bash
git add .
git commit -m "Update personal homepage"
git push origin main
```

GitHub Pages will automatically rebuild and publish the latest version.
